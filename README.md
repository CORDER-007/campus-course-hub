# Course Hub · 课程表与选课系统

这是一个面向学生的课程表与选课系统前端实践项目，使用 Vue 3 + Vite + Pinia + Element Plus 构建。项目采用本地模拟数据，不依赖后端和数据库，适合直接在 IDEA 中打开和运行。

## 功能概览

- 学习总览：已选课程、学分、课时、培养方案进度和选课提醒
- 课程中心：关键词搜索、分类筛选、排序、课程卡片和名额进度
- 选课操作：正常选课、重复选课拦截、满员拦截、时间冲突检测、退选
- 我的课表：周视图课表、已选课程表格、打印课表
- 数据持久化：使用 `localStorage` 保存已选课程，刷新后自动恢复
- 响应式布局：支持桌面端、平板和窄屏浏览器

## IDEA 运行

1. 使用 IDEA 打开当前项目根目录。
2. 确认 Node.js 20+ 和 npm 10+ 已安装。
3. 在 IDEA Terminal 执行：

```bash
pnpm install
pnpm dev
```

4. 浏览器访问 `http://localhost:5173`。
5. 构建生产版本：

```bash
pnpm build
pnpm preview
```

如果使用 npm，将命令中的 `pnpm` 替换为 `npm` 即可。

## 选课规则

- 已选课程不能重复添加。
- 课程已达到容量上限时不能选课。
- 同一星期、同一节次的课程视为时间冲突。
- 成功选课或退选后立即写入本地存储。
- 课程数据只用于前端教学演示，不代表真实教务系统数据。

## 验收建议

推荐演示顺序：进入学习总览 → 浏览课程 → 搜索“JavaScript” → 重置筛选 → 选一门课程 → 选择同一时间段课程验证冲突提示 → 打开我的课表 → 退选 → 刷新页面验证数据持久化。
