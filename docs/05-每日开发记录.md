# 05 每日开发记录（初稿）

> 以下为过程记录模板和项目初稿，提交前应按真实执行时间、命令、截图和 Git 记录校对。

## 9月7日：需求与环境

- 今日目标：确认选题，检查 Node.js、IDEA、Git 和浏览器环境。
- 完成内容：确定课程表与选课系统；建立 Vue + Vite 项目目录；设计课程数据字段。
- 遇到问题：空仓库没有现成脚手架，需要先规划目录结构。
- 解决方法：先搭建最小工程骨架，再逐页开发。
- AI 工具使用：辅助整理课程需求和开发任务，人工检查后采用。
- 明日计划：完成路由、布局和 Pinia 状态层。

## 9月8日：Vue 架构

- 今日目标：完成侧边栏、顶部栏和主页面路由。
- 完成内容：建立总览、课程中心、我的课表三个路由；集中维护课程数据和选课状态。
- 遇到问题：多个页面需要共享已选课程状态。
- 解决方法：使用 Pinia store 统一管理，页面只通过 store 操作。
- AI 工具使用：辅助检查组件拆分和状态流转，人工验证页面行为。
- 明日计划：完成课程筛选、选课、退选和冲突检测。

## 9月9日：核心交互

- 今日目标：完成课程中心功能。
- 完成内容：关键词搜索、分类筛选、排序、名额显示、重复选课和时间冲突提示。
- 遇到问题：选课后首页和课表需要同步刷新。
- 解决方法：使用 computed 派生统计数据和课表数据，避免页面重复维护。
- AI 工具使用：辅助排查边界条件，实际测试以浏览器结果为准。
- 明日计划：完成周课表、打印入口和响应式样式。

## 9月10日：课表与适配

- 今日目标：完成周视图课表和窄屏布局。
- 完成内容：按星期、节次生成课表网格；支持退选；增加空状态和打印样式。
- 遇到问题：窄屏课表列宽不足。
- 解决方法：课表保持最小宽度并允许横向滚动，其他内容改为单列。
- AI 工具使用：辅助检查 CSS 断点，人工在浏览器中复核。
- 明日计划：执行构建、整理运行说明和课程报告。

- 测试内容：正常选课、重复选课、时间冲突、退选、筛选、刷新恢复和窄屏布局。
