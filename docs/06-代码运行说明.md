# 06 代码运行说明

## 环境要求

- Node.js 20+
- npm 10+ 或 pnpm
- IDEA、Chrome/Edge

## 安装运行

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址，默认是 `http://localhost:5173`。

## 构建预览

```bash
pnpm build
pnpm preview
```

生产文件位于 `dist/`。项目使用 Hash 路由，静态部署时可直接访问。

## 核心验证

1. 首页点击“浏览课程”。
2. 在搜索框输入 `JavaScript`，确认筛选结果变化。
3. 重置筛选条件，选择一门课程。
4. 再选择同一星期、同一节次的课程，确认出现时间冲突提示。
5. 打开“我的课表”，确认课程显示在对应网格。
6. 退选课程并刷新浏览器，确认状态保存。

## 常见问题

- 首次打开默认提供 3 门演示课程，方便展示；退选后可以从课程中心重新操作。
- 如果需要清空演示数据，可在浏览器控制台执行 `localStorage.removeItem('campus-course-hub-selected')`，然后刷新页面。
- 当前数据是前端模拟数据，不能替代真实教务系统。
