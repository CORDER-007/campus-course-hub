## 选题理由

本项目面向高校学生选课场景，围绕课程浏览、选课、退选、课表查看和学分统计设计。项目不依赖真实教务后端，能够在一周实践周期内完成从需求分析、架构设计、编码实现、测试到构建部署的完整前端流程。

## 预期功能

1. 学习总览：查看已选课程、已获得学分、本周课时和培养方案完成度。
2. 课程中心：按课程名、编号、教师和类别搜索筛选，支持排序。
3. 选退课程：加入课表、退选课程、重复选课和名额校验。
4. 冲突检测：基于星期和节次阻止时间冲突课程。
5. 我的课表：以周视图展示课程，并提供打印入口。
6. 数据持久化：使用浏览器 `localStorage` 保存选课结果。

## 技术路线

- 前端框架：Vue 3 + Vite
- 状态管理：Pinia
- 路由：Vue Router Hash 模式
- UI 组件：Element Plus
- 图标：Lucide Vue Next
- 数据来源：本地 JavaScript 模拟数据
- 工程约束：跨屏响应式适配、选课冲突校验、数据刷新恢复
