# 02 环境配置文档（初稿）

## 1. 开发环境

- 操作系统：Windows 10/11（以实际设备为准）
- IDE：IntelliJ IDEA（用于打开项目和编辑文件）
- Node.js：建议 20.x 或更高 LTS 版本
- npm：建议 10.x 或更高版本
- 包管理器：pnpm 或 npm
- 浏览器：Chrome / Edge，使用 DevTools 调试
- 版本管理：Git

## 2. 安装与验证

```bash
node -v
npm -v
git --version
```

在项目根目录安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm dev
```

构建生产版本：

```bash
pnpm build
```

## 3. IDEA 使用方式

1. 选择 `File > Open`，打开项目根目录。
2. 在 IDEA Terminal 进入项目根目录。
3. 执行 `pnpm install` 安装依赖。
4. 执行 `pnpm dev`，根据终端地址打开浏览器。
5. 编辑 `src` 目录中的 Vue、JavaScript 和 CSS 文件，保存后页面自动热更新。

## 4. 环境问题排查

- 端口被占用：修改 `vite.config.js` 中的 `server.port`，或结束占用 5173 端口的进程。
- 依赖安装失败：检查网络和 npm/pnpm registry 配置，重新执行安装命令。
- 页面空白：打开浏览器控制台，检查导入路径、模板语法和运行时异常。
- 刷新路由异常：本项目使用 Hash 路由，静态部署时不依赖服务端回退配置。

## 5. 部署环境

项目使用相对资源路径 `base: './'`，可部署到支持静态文件托管的平台。部署前执行 `pnpm build`，上传 `dist` 目录。线上地址请在实际部署后填写：`[待填写]`。
